Activa le copia, le selection de texto e le menus del clic dextre in paginas web que los restringe.

Enable Copy and Right Click es un extension legier e de codice aperte que restaura le copia, le selection de texto e le clic dextre normal in paginas web que restringe iste actiones.

Clicca sur le icone del extension in le barra de instrumentos o usa le via breve de claviero pro activar le copia e le clic dextre in le scheda actual.

Tu pote anque adder sitos web fidabile al lista de sitos automatic. Le extension activara alora le copia e le clic dextre automaticamente cata vice que tu visita iste sitos.

FUNCTIONES PRINCIPAL

• Activa le copia e le selection de texto in paginas web restringite
• Activa le menus contextual del clic dextre
• Activa copiar, taliar, collar, seliger texto e traher
• Activation con un clic ab le barra de instrumentos
• Via breve de claviero pro un activation rapide
• Activation automatic in le sitos que tu selige
• Functiona in iframes accessibile ubi le permissiones del navigator lo permitte
• Monstra un insignia ON post le activation manual
• Nulle menus emergente
• Nulle analyse o traciamento
• Nulle codice remote o requestas de rete

VIAS BREVE DE CLAVIERO PREDEFINITE

• Windows, Linux, ChromeOS, GooglebookOS e Android: Alt+C
• macOS: Command+Shift+Y

Le via breve de claviero face le mesme cosa que un clic sur le icone del extension.

CAMBIAR LE VIA BREVE DE CLAVIERO

1. Aperi le menu de Firefox e selige Additivos e themas.
2. Clicca sur le icone de rota dentate in le pagina Extensiones.
3. Selige Gerer le vias breve del extensiones.
4. Trova Enable Copy and Right Click e entra le via breve que tu prefere.

SITOS AUTOMATIC

Aperi le pagina de optiones del extension e adde un dominio como:

example.com

Le extension demandara permission solmente pro le sito web que tu adde. Post que le permission es concedite, le copia, le selection de texto e le clic dextre essera activate automaticamente in ille sito.

Tu pote remover un sito automatic a omne momento ab le pagina de optiones.

APERIR LE PAGINA DE OPTIONES

1. Aperi le menu de Firefox e selige Additivos e themas.
2. Trova Enable Copy and Right Click e clicca sur le menu a tres punctos al latere.
3. Selige Preferentias.

PRIVATESSA

• Nulle analyse o traciamento
• Nulle collection de datos
• Nulle collection del chronologia de navigation
• Nulle requestas de rete
• Nulle codice remote
• Nulle JavaScript externe
• Le preferentias del sitos automatic es salvate localmente in tu navigator
• Le permissiones de sito es demandate solmente quando tu adde explicitemente un sito

Tote le restauration del copia e del clic dextre occurre localmente in tu navigator.

PRESTATIONES

Le extension es legier e guidate per eventos.

Illo non face labor continue in le fundo quando illo es inactive. Le activation manual se executa solmente quando tu clicca sur le icone del barra de instrumentos o usa le via breve de claviero. Le activation automatic se executa solmente in le sitos web que tu ha addite explicitemente.

Il non ha interrogation periodic, activitate de rete in le fundo, SDK de analyse, configuration remote o bucla de surveliantia continue del paginas.
