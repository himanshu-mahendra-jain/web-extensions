浏览器启动时，清除除你保留的网站以外所有网站的历史记录、Cookie 和网站数据。

Clear Browsing Data Except Kept Sites 是一款轻量的开源扩展程序，会删除你未选择保留的所有网站的历史记录、Cookie 和网站数据。

在设置中添加你想保持登录、想被记住的网站，然后开启清除。每次启动浏览器时，扩展程序都会删除其他所有网站的历史记录、Cookie 和网站数据。你也可以随时点击“立即清除”进行清除。

提示：在 Edge 的“扩展”菜单中为 Clear Browsing Data Except Kept Sites 开启“在工具栏中显示”，即可快速使用。

主要功能

• 历史记录和 Cookie 永不清除的网站列表，支持以文本文件导入和导出
• 开启后，在浏览器启动时清除其他所有网站的历史记录和 Cookie
• 随时用“立即清除”清除，并用“清除残留”清除已找不到的网站残留的数据
• 自动保留所保留网站的子域名
• 保留所保留网站为保持登录所需的父域名 Cookie
• 清除分区（第三方）Cookie；所保留网站的分区 Cookie 只在所保留的网站下保留
• 清除未保留网站的本地存储、IndexedDB、Service Worker 和缓存
• 在设置中显示上次清除的结果
• 网站访问权限关闭、无法删除 Cookie 时发出警告
• 无分析或跟踪
• 无远程代码或网络请求

保留的网站

打开设置并添加一个域名，例如：

example.com

要一次添加多个，用逗号分隔。

“导出”会把列表保存为文本文件，每行一个域名。“导入”会用文本文件中的网站替换列表，如果这样会移除你现在保留的网站，会先发出警告。

像 mail.example.com/inbox 这样的地址会缩减为其域名，开头的 www. 会被去掉。也接受 localhost 和 192.168.1.1 这样的 IPv4 地址。

保留 example.com 会保留 example.com 及其所有子域名的历史记录、Cookie 和网站数据。保留 mail.example.com 也会保留 example.com 的 Cookie，因为子域名的登录信息通常存放在其中。

打开设置

安装后设置会自动打开，你可以在开启清除前先填好列表。之后，点击工具栏中的扩展程序图标，或者：

1. 右键点击工具栏中的扩展程序图标。
2. 选择“扩展选项”。

启动时清除

安装后清除处于关闭状态，在你要求之前不会删除任何内容。设置会显示“清除已关闭”提示和“开启清除”按钮。开启时会先显示警告：每次启动都会删除除保留网站外所有网站的历史记录和 Cookie，并让你退出这些网站的登录；如果没有保留任何网站，则会退出所有网站的登录。

开启后，每次启动浏览器时都会运行清除，因为浏览器不允许扩展程序在关闭时运行。启动时清除会删除上一次会话留下的内容。可在设置中用“浏览器启动时自动清除”关闭或重新开启。

立即清除与清除残留

设置中的“立即清除”会立即清除。如果没有保留任何网站，会先显示一条红色警告，说明所有内容都将被删除。设置会显示上次清除的时间，以及删除了多少条历史记录和多少个 Cookie。

一次清除删除了某个网站的历史记录和 Cookie 后，之后的清除就再也找不到该网站，因此它的本地存储、数据库和缓存会留下来。“清除残留”会运行一次清除，然后删除所有未保留网站的数据，无论是否找到它们。此时浏览器只能排除完全匹配的网站，因此所保留网站的数据只为它自己以及清除时在历史记录、Cookie 和打开的标签页中找到的保留网站保留；红色警告会先说明这一点。

网站访问权限

只有扩展程序有权访问的网站才能删除 Cookie，所以它会请求访问所有网站。如果你限制网站访问权限，例如设为“点击时”，历史记录仍会被清除，但会跳过 Cookie，设置中会显示“允许访问网站”按钮。

限制

• 启动时恢复的标签页可能会在清除运行期间设置新的 Cookie。这些 Cookie 会保留到下次启动或下次“立即清除”。
• 其他网站数据，例如会话存储、网站权限以及通过 File System API 保存的文件，不会被清除。
• 如果浏览器同步包含历史记录，被删除的历史记录也可能会从你的其他设备上删除。
• 只有在扩展程序获准在 InPrivate 中运行时，才会清除 InPrivate 窗口。无论如何，Edge 都会在关闭这些窗口时丢弃其数据。
• 无法将 IPv6 地址添加到列表。

隐私

• 无分析或跟踪
• 不收集数据
• 无网络请求
• 无远程代码
• 无外部 JavaScript
• 历史记录和 Cookie 只在你的浏览器中读取，仅用于决定要删除什么
• 列表和设置存储在你的浏览器本地

性能

浏览时扩展程序不会做任何事。它只在开启清除后于浏览器启动时运行一次，以及在你点击“立即清除”或“清除残留”时运行。

首次清除较长的历史记录可能需要几分钟，因为每条历史记录都要单独删除。在此期间你可以继续浏览。之后的清除只会删除上一次会话的记录。
