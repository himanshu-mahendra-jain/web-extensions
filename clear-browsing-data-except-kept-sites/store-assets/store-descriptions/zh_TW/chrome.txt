瀏覽器啟動時，清除你保留的網站以外所有網站的瀏覽記錄、Cookie 和網站資料。

Clear Browsing Data Except Kept Sites 是一款輕量的開放原始碼擴充功能，會刪除你未選擇保留的所有網站的瀏覽記錄、Cookie 和網站資料。

在設定中新增你想保持登入、想被記住的網站，然後開啟清除功能。每次啟動瀏覽器時，擴充功能都會刪除其他所有網站的瀏覽記錄、Cookie 和網站資料。你也可以隨時點選「立即清除」進行清除。

提示：在 Chrome 的「擴充功能」選單（拼圖圖示）中將本擴充功能釘選到工具列，隨時都能方便使用。

主要功能

• 瀏覽記錄和 Cookie 永不清除的網站清單，支援以文字檔匯入和匯出
• 開啟後，在瀏覽器啟動時清除其他所有網站的瀏覽記錄和 Cookie
• 隨時用「立即清除」清除，並用「清除殘留」清除已找不到的網站殘留的資料
• 自動保留所保留網站的子網域
• 保留所保留網站為保持登入所需的上層網域 Cookie
• 清除分區（第三方）Cookie；所保留網站的分區 Cookie 只在所保留的網站下保留
• 清除未保留網站的本機儲存空間、IndexedDB、Service Worker 和快取
• 在設定中顯示上次清除的結果
• 網站存取權關閉、無法刪除 Cookie 時發出警告
• 無分析或追蹤
• 無遠端程式碼或網路要求

保留的網站

開啟設定並新增一個網域，例如：

example.com

要一次新增多個，請用逗號分隔。

「匯出」會把清單儲存為文字檔，每行一個網域。「匯入」會用文字檔中的網站取代清單，如果這樣會移除你現在保留的網站，會先發出警告。

像 mail.example.com/inbox 這樣的位址會縮減為其網域，開頭的 www. 會被去掉。也接受 localhost 和 192.168.1.1 這樣的 IPv4 位址。

保留 example.com 會保留 example.com 及其所有子網域的瀏覽記錄、Cookie 和網站資料。保留 mail.example.com 也會保留 example.com 的 Cookie，因為子網域的登入資訊通常存放在其中。

開啟設定

安裝後設定會自動開啟，你可以在開啟清除功能前先填好清單。之後，點選工具列中的擴充功能圖示，或者：

1. 在工具列中的擴充功能圖示上按一下右鍵。
2. 選取「選項」。

啟動時清除

安裝後清除功能處於關閉狀態，在你要求之前不會刪除任何內容。設定會顯示「清除功能已關閉」通知和「開啟清除功能」按鈕。開啟時會先顯示警告：每次啟動都會刪除保留網站以外所有網站的瀏覽記錄和 Cookie，並讓你登出這些網站；如果沒有保留任何網站，則會登出所有網站。

開啟後，每次啟動瀏覽器時都會執行清除，因為瀏覽器不允許擴充功能在關閉時執行。啟動時清除會刪除上一次工作階段留下的內容。可在設定中用「瀏覽器啟動時自動清除」關閉或重新開啟。

立即清除與清除殘留

設定中的「立即清除」會立即清除。如果沒有保留任何網站，會先顯示一則紅色警告，說明所有內容都將被刪除。設定會顯示上次清除的時間，以及刪除了多少筆瀏覽記錄和多少個 Cookie。

一次清除刪除了某個網站的瀏覽記錄和 Cookie 後，之後的清除就再也找不到該網站，因此它的本機儲存空間、資料庫和快取會留下來。「清除殘留」會執行一次清除，然後刪除所有未保留網站的資料，無論是否找到它們。此時瀏覽器只能排除完全相符的網站，因此所保留網站的資料只為它自己以及清除時在瀏覽記錄、Cookie 和開啟的分頁中找到的保留網站保留；紅色警告會先說明這一點。

網站存取權

只有擴充功能有權存取的網站才能刪除 Cookie，所以它會要求存取所有網站。如果你限制網站存取權，例如設為「點選時」，瀏覽記錄仍會被清除，但會略過 Cookie，設定中會顯示「允許存取網站」按鈕。

限制

• 啟動時還原的分頁可能會在清除執行期間設定新的 Cookie。這些 Cookie 會保留到下次啟動或下次「立即清除」。
• 其他網站資料，例如工作階段儲存空間、網站權限以及透過 File System API 儲存的檔案，不會被清除。
• 如果瀏覽器同步包含瀏覽記錄，被刪除的瀏覽記錄也可能會從你的其他裝置上刪除。
• 只有在擴充功能獲准在無痕模式下執行時，才會清除無痕視窗。無論如何，Chrome 都會在關閉這些視窗時捨棄其資料。
• 無法將 IPv6 位址新增到清單。

隱私權

• 無分析或追蹤
• 不收集資料
• 無網路要求
• 無遠端程式碼
• 無外部 JavaScript
• 瀏覽記錄和 Cookie 只在你的瀏覽器中讀取，僅用於決定要刪除什麼
• 清單和設定儲存在你的瀏覽器本機

效能

瀏覽時擴充功能不會做任何事。它只在開啟清除功能後於瀏覽器啟動時執行一次，以及在你點選「立即清除」或「清除殘留」時執行。

首次清除較長的瀏覽記錄可能需要幾分鐘，因為每筆瀏覽記錄都要個別刪除。在此期間你可以繼續瀏覽。之後的清除只會刪除上一次工作階段的記錄。
