ล้างประวัติ คุกกี้ และข้อมูลเว็บไซต์เมื่อเบราว์เซอร์เริ่มทำงาน สำหรับทุกเว็บไซต์ยกเว้นเว็บไซต์ที่คุณเก็บไว้

Clear Browsing Data Except Kept Sites เป็นส่วนขยายโอเพนซอร์สขนาดเล็กที่ลบรายการประวัติ คุกกี้ และข้อมูลเว็บไซต์ของทุกเว็บไซต์ที่คุณไม่ได้เลือกเก็บไว้

ในการตั้งค่า ให้เพิ่มเว็บไซต์ที่คุณต้องการคงการลงชื่อเข้าใช้ไว้และต้องการให้จดจำคุณ แล้วเปิดการล้าง ทุกครั้งที่เบราว์เซอร์เริ่มทำงาน ส่วนขยายจะลบประวัติ คุกกี้ และข้อมูลเว็บไซต์ของเว็บไซต์อื่นทั้งหมด คุณยังล้างได้ทุกเมื่อด้วย "ล้างเลย"

เคล็ดลับ: ในเมนูส่วนขยายของ Edge ให้เปิดตัวเลือก «แสดงในแถบเครื่องมือ» สำหรับ Clear Browsing Data Except Kept Sites เพื่อการใช้งานที่สะดวก

คุณสมบัติหลัก

• รายการเว็บไซต์ที่ไม่มีวันถูกล้างประวัติและคุกกี้ พร้อมการนำเข้าและส่งออกเป็นไฟล์ข้อความ
• ล้างประวัติและคุกกี้ของเว็บไซต์อื่นทั้งหมดเมื่อเบราว์เซอร์เริ่มทำงาน หลังจากที่คุณเปิดใช้
• ล้างได้ทุกเมื่อด้วย "ล้างเลย" และล้างข้อมูลที่เหลือของเว็บไซต์ที่หาไม่พบแล้วด้วย "ล้างส่วนที่เหลือ"
• เก็บโดเมนย่อยของเว็บไซต์ที่เก็บไว้โดยอัตโนมัติ
• เก็บคุกกี้ของโดเมนหลักที่เว็บไซต์ที่เก็บไว้ต้องใช้เพื่อให้คุณลงชื่อเข้าใช้อยู่
• ล้างคุกกี้ที่แบ่งพาร์ติชัน (ของบุคคลที่สาม) คุกกี้ที่แบ่งพาร์ติชันของเว็บไซต์ที่เก็บไว้จะคงอยู่ภายใต้เว็บไซต์ที่เก็บไว้เท่านั้น
• ล้างพื้นที่เก็บข้อมูลในเครื่อง, IndexedDB, service worker และแคชของเว็บไซต์ที่ไม่ได้เก็บไว้
• แสดงผลการล้างครั้งล่าสุดในการตั้งค่า
• เตือนเมื่อการเข้าถึงเว็บไซต์ปิดอยู่และลบคุกกี้ไม่ได้
• ไม่มีการวิเคราะห์หรือการติดตาม
• ไม่มีโค้ดระยะไกลหรือคำขอเครือข่าย

เว็บไซต์ที่เก็บไว้

เปิดการตั้งค่าแล้วเพิ่มโดเมน เช่น

example.com

หากต้องการเพิ่มหลายรายการพร้อมกัน ให้คั่นด้วยเครื่องหมายจุลภาค

"ส่งออก" จะบันทึกรายการเป็นไฟล์ข้อความ บรรทัดละหนึ่งโดเมน "นำเข้า" จะแทนที่รายการด้วยเว็บไซต์จากไฟล์ข้อความ และจะเตือนก่อนหากเว็บไซต์ที่คุณเก็บไว้ตอนนี้จะหายไป

ที่อยู่อย่าง mail.example.com/inbox จะถูกย่อเหลือโดเมน และ www. ที่นำหน้าจะถูกตัดออก ยอมรับ localhost และที่อยู่ IPv4 อย่าง 192.168.1.1 ด้วย

การเก็บ example.com จะเก็บประวัติ คุกกี้ และข้อมูลเว็บไซต์ของ example.com และโดเมนย่อยทั้งหมด การเก็บ mail.example.com จะเก็บคุกกี้ของ example.com ไว้ด้วย เพราะมักมีข้อมูลการลงชื่อเข้าใช้ของโดเมนย่อย

การเปิดการตั้งค่า

การตั้งค่าจะเปิดขึ้นเองหลังติดตั้ง เพื่อให้คุณกรอกรายการได้ก่อนเปิดการล้าง ภายหลังให้คลิกไอคอนส่วนขยายในแถบเครื่องมือ หรือ:

1. คลิกขวาที่ไอคอนของส่วนขยายในแถบเครื่องมือ
2. เลือก "ตัวเลือกส่วนขยาย"

ล้างเมื่อเริ่มทำงาน

หลังติดตั้ง การล้างจะปิดอยู่ จึงไม่มีอะไรถูกลบจนกว่าคุณจะสั่ง การตั้งค่าจะแสดงประกาศ "การล้างปิดอยู่" พร้อมปุ่ม "เปิดการล้าง" เมื่อเปิดจะมีคำเตือนแสดงก่อน: การเริ่มทำงานแต่ละครั้งจะลบประวัติและคุกกี้ของทุกเว็บไซต์ยกเว้นที่เก็บไว้ และนำคุณออกจากระบบของเว็บไซต์เหล่านั้น หรือของทุกเว็บไซต์หากไม่ได้เก็บไว้เลย

เมื่อเปิดอยู่ การล้างจะทำงานทุกครั้งที่เบราว์เซอร์เริ่มทำงาน เพราะเบราว์เซอร์ไม่อนุญาตให้ส่วนขยายทำงานตอนปิด การล้างเมื่อเริ่มทำงานจะลบสิ่งที่เซสชันก่อนหน้าทิ้งไว้ ปิดหรือเปิดอีกครั้งได้ด้วย "ล้างโดยอัตโนมัติเมื่อเบราว์เซอร์เริ่มทำงาน" ในการตั้งค่า

ล้างเลยและล้างส่วนที่เหลือ

"ล้างเลย" ในการตั้งค่าจะล้างทันที หากไม่ได้เก็บเว็บไซต์ใดไว้ จะมีคำเตือนสีแดงแสดงก่อนว่าทุกอย่างจะถูกลบ การตั้งค่าจะแสดงว่าล้างครั้งล่าสุดเมื่อใดและลบรายการประวัติและคุกกี้ไปกี่รายการ

หลังจากการล้างลบประวัติและคุกกี้ของเว็บไซต์หนึ่งไปแล้ว การล้างครั้งต่อไปจะหาเว็บไซต์นั้นไม่พบอีก พื้นที่เก็บข้อมูลในเครื่อง ฐานข้อมูล และแคชของเว็บไซต์นั้นจึงยังคงอยู่ "ล้างส่วนที่เหลือ" จะล้างหนึ่งครั้ง แล้วลบข้อมูลของทุกเว็บไซต์ที่คุณไม่ได้เก็บไว้ ไม่ว่าจะพบหรือไม่ ในขั้นนี้เบราว์เซอร์ยกเว้นได้เฉพาะเว็บไซต์ที่ตรงกันพอดี เว็บไซต์ที่เก็บไว้จึงเก็บข้อมูลไว้ให้ตัวเองและเว็บไซต์ที่เก็บไว้ที่การล้างพบในประวัติ คุกกี้ และแท็บที่เปิดอยู่เท่านั้น คำเตือนสีแดงจะบอกเรื่องนี้ก่อน

การเข้าถึงเว็บไซต์

ลบคุกกี้ได้เฉพาะเว็บไซต์ที่ส่วนขยายเข้าถึงได้ ส่วนขยายจึงขอสิทธิ์เข้าถึงทุกเว็บไซต์ หากคุณจำกัดการเข้าถึงเว็บไซต์ เช่น เป็น "เมื่อคลิก" ประวัติจะยังถูกล้าง แต่จะข้ามคุกกี้ และการตั้งค่าจะแสดงปุ่ม "อนุญาตการเข้าถึงเว็บไซต์"

ข้อจำกัด

• แท็บที่กู้คืนตอนเริ่มทำงานอาจตั้งคุกกี้ใหม่ระหว่างที่การล้างกำลังทำงาน คุกกี้เหล่านั้นจะอยู่จนถึงการเริ่มทำงานครั้งถัดไปหรือ "ล้างเลย" ครั้งถัดไป
• ข้อมูลเว็บไซต์อื่นๆ เช่น พื้นที่เก็บข้อมูลเซสชัน สิทธิ์ของเว็บไซต์ และไฟล์ที่บันทึกผ่าน File System API จะไม่ถูกล้าง
• หากการซิงค์ของเบราว์เซอร์รวมประวัติไว้ด้วย รายการประวัติที่ถูกลบอาจถูกลบจากอุปกรณ์อื่นของคุณด้วย
• หน้าต่าง InPrivate จะถูกล้างเฉพาะเมื่ออนุญาตส่วนขยายใน InPrivate อย่างไรก็ตาม Edge จะทิ้งข้อมูลของหน้าต่างเหล่านั้นเมื่อปิดอยู่แล้ว
• เพิ่มที่อยู่ IPv6 ลงในรายการไม่ได้

ความเป็นส่วนตัว

• ไม่มีการวิเคราะห์หรือการติดตาม
• ไม่มีการเก็บรวบรวมข้อมูล
• ไม่มีคำขอเครือข่าย
• ไม่มีโค้ดระยะไกล
• ไม่มี JavaScript ภายนอก
• อ่านประวัติและคุกกี้เพื่อตัดสินใจว่าจะลบอะไรเท่านั้น และอ่านในเบราว์เซอร์ของคุณเท่านั้น
• รายการและการตั้งค่าจัดเก็บไว้ในเบราว์เซอร์ของคุณ

ประสิทธิภาพ

ส่วนขยายไม่ทำอะไรเลยขณะที่คุณท่องเว็บ ส่วนขยายจะทำงานครั้งเดียวเมื่อเบราว์เซอร์เริ่มทำงาน หากเปิดการล้างไว้ และเมื่อคุณคลิก "ล้างเลย" หรือ "ล้างส่วนที่เหลือ"

การล้างประวัติยาวๆ ครั้งแรกอาจใช้เวลาสองสามนาที เพราะรายการประวัติแต่ละรายการจะถูกลบแยกกัน ระหว่างนั้นคุณท่องเว็บต่อได้ การล้างครั้งต่อไปจะลบเฉพาะรายการของเซสชันก่อนหน้า
