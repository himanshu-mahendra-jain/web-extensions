ブラウザの起動時に、残すサイト以外のすべてのサイトの履歴、Cookie、サイトデータを消去します。

Android 版 Firefox では拡張機能が履歴を削除できないため、Cookie とサイトデータのみが消去されます。

Clear Browsing Data Except Kept Sites は、残すと決めたサイト以外のすべてのサイトの履歴、Cookie、サイトデータを削除する、軽量なオープンソースの拡張機能です。

設定で、ログインしたままにしておきたいサイトや覚えておきたいサイトを追加し、消去をオンにします。ブラウザを起動するたびに、拡張機能がそれ以外のすべてのサイトの履歴と Cookie を削除します。「今すぐ消去」でいつでも消去することもできます。

主な機能

• 履歴と Cookie を消去しないサイトの一覧（テキストファイルでのインポートとエクスポートに対応）
• オンにすると、ブラウザの起動時にそれ以外のすべてのサイトの履歴と Cookie を消去
• 設定の「今すぐ消去」でいつでも消去
• 残すサイトのサブドメインも自動的に残す
• 残すサイトでログインしたままにするために必要な親ドメインの Cookie を残す
• パーティション分割された（サードパーティ）Cookie とコンテナーの Cookie を消去。残すサイトのパーティション分割 Cookie は、残すサイトの下にあるものだけが残ります
• 残さないサイトのローカルストレージ、IndexedDB、Service Worker、キャッシュを消去
• 最後の消去の結果を設定に表示
• サイトへのアクセスがオフで Cookie を削除できないときに警告
• 分析やトラッキングなし
• リモートコードやネットワーク リクエストなし

残すサイト

設定を開き、ドメインを追加します。例:

example.com

複数をまとめて追加するには、カンマで区切ります。

「エクスポート」は一覧を 1 行に 1 ドメインのテキストファイルに保存します。「インポート」は一覧をテキストファイルのサイトで置き換えます。今残しているサイトがなくなる場合は、先に警告します。

mail.example.com/inbox のようなアドレスはドメインだけになり、先頭の www. は省かれます。localhost や 192.168.1.1 のような IPv4 アドレスも使えます。

example.com を残すと、example.com とそのすべてのサブドメインの履歴と Cookie が残ります。mail.example.com を残すと example.com の Cookie も残ります。サブドメインのログイン情報がそこに入っていることが多いためです。

設定を開く

インストール後に設定が自動的に開くので、消去をオンにする前に一覧を作れます。その後は、ツールバーの拡張機能アイコンをクリックします。Android 版 Firefox では、ブラウザの「拡張機能」メニューで Clear Browsing Data Except Kept Sites をタップします。

アドオンマネージャーから開くこともできます:

1. Firefox のメニューを開き、[アドオンとテーマ] を選びます。
2. Clear Browsing Data Except Kept Sites を見つけ、その横にある三点メニューをクリックします。
3. [設定] を選択します。

起動時の消去

インストール直後は消去がオフなので、指示するまで何も削除されません。設定には「消去はオフです」というお知らせと「消去をオンにする」ボタンが表示されます。オンにすると、まず警告が表示されます。起動のたびに、残すサイト以外のすべてのサイトの履歴と Cookie が削除され、それらのサイトから（残すサイトがない場合はすべてのサイトから）ログアウトされます。

オンにすると、消去はブラウザの起動のたびに実行されます。ブラウザは終了時に拡張機能を実行させないためです。起動時の消去は、前回のセッションが残したものを削除します。設定の「ブラウザの起動時に自動で消去する」でオフにしたり、オンに戻したりできます。

今すぐ消去

設定の「今すぐ消去」はすぐに消去します。残すサイトがない場合は、すべて削除されることを知らせる赤い警告が先に表示されます。設定には、最後の消去がいつだったか、履歴と Cookie をいくつ削除したかが表示されます。

サイトへのアクセス

Cookie は拡張機能がアクセスできるサイトからしか削除できないため、すべてのサイトへのアクセスを求めます。サイトへのアクセスをオフにすると、履歴は引き続き消去されますが Cookie はスキップされ、設定に「サイトへのアクセスを許可」ボタンが表示されます。

制限事項

• 起動時に復元されたタブは、消去の実行中に新しい Cookie を設定することがあります。その Cookie は次回の起動か「今すぐ消去」まで残ります。
• Firefox は選んだサイトを除いてサイトデータを削除することができないため、拡張機能は履歴、Cookie、開いているタブから見つけた残さないサイトのそれぞれについて、ローカルストレージ、IndexedDB、Service Worker を削除します。そのどれにも現れないサイトのデータは残ります。残すサブドメインを持つサイトは Service Worker を残します。Firefox はそのサブドメインの Service Worker も一緒に削除してしまうためです。キャッシュは Firefox がサイトごとに削除できないため、すべてのサイトで消去されます。これでログアウトされることはありません。
• Firefox は Cache Storage（Service Worker が保存するオフライン用ファイル）をサイトごとに削除できないため、これは消去されません。拡張機能が届かないものを削除するには、設定 > プライバシーとセキュリティ > Cookie とサイトデータ > データを管理 を使います。
• ブラウザの同期に履歴が含まれている場合、削除した履歴はほかのデバイスからも削除されることがあります。
• プライベートウィンドウは、拡張機能の実行が許可されている場合にのみ消去されます。

プライバシー

• 分析やトラッキングなし
• データ収集なし
• ネットワーク リクエストなし
• リモートコードなし
• 外部 JavaScript なし
• 履歴と Cookie は削除する対象を決めるためだけに、お使いのブラウザ内でのみ読み取られます
• 一覧と設定はお使いのブラウザ内にローカルに保存されます

パフォーマンス

拡張機能はブラウジング中は何もしません。動作するのは、消去がオンのときのブラウザ起動時に 1 回と、「今すぐ消去」をクリックしたときだけです。

長い履歴の最初の消去には数分かかることがあります。履歴は 1 件ずつ削除されるためです。その間もブラウジングを続けられます。以降の消去では前回のセッションの履歴だけが削除されます。
