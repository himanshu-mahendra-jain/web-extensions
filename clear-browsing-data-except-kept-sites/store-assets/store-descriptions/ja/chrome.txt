ブラウザの起動時に、残すサイト以外のすべてのサイトの履歴、Cookie、サイトデータを消去します。

Clear Browsing Data Except Kept Sites は、残すと決めたサイト以外のすべてのサイトの履歴、Cookie、サイトデータを削除する、軽量なオープンソースの拡張機能です。

設定で、ログインしたままにしておきたいサイトや覚えておきたいサイトを追加し、消去をオンにします。ブラウザを起動するたびに、拡張機能がそれ以外のすべてのサイトの履歴、Cookie、サイトデータを削除します。「今すぐ消去」でいつでも消去することもできます。

ヒント: Chrome の「拡張機能」メニュー（パズルのピースのアイコン）から本拡張機能を固定（ピン留め）すると、ツールバーに常時表示できます。

主な機能

• 履歴と Cookie を消去しないサイトの一覧（テキストファイルでのインポートとエクスポートに対応）
• オンにすると、ブラウザの起動時にそれ以外のすべてのサイトの履歴と Cookie を消去
• 「今すぐ消去」でいつでも消去、「残りを消去」で見つからなくなったサイトの残りのデータも消去
• 残すサイトのサブドメインも自動的に残す
• 残すサイトでログインしたままにするために必要な親ドメインの Cookie を残す
• パーティション分割された（サードパーティ）Cookie を消去。残すサイトのパーティション分割 Cookie は、残すサイトの下にあるものだけが残ります
• 残さないサイトのローカルストレージ、IndexedDB、Service Worker、キャッシュを消去
• 最後の消去の結果を設定に表示
• サイトへのアクセスがオフで Cookie を削除できないときに警告
• 分析やトラッキングなし
• リモートコードやネットワーク リクエストなし

残すサイト

設定を開き、ドメインを追加します。例:

example.com

複数をまとめて追加するには、カンマで区切ります。

「エクスポート」は一覧を 1 行に 1 ドメインのテキストファイルに保存します。「インポート」は一覧をテキストファイルのサイトで置き換えます。今残しているサイトがなくなる場合は、先に警告します。

mail.example.com/inbox のようなアドレスはドメインだけになり、先頭の www. は省かれます。localhost や 192.168.1.1 のような IPv4 アドレスも使えます。

example.com を残すと、example.com とそのすべてのサブドメインの履歴、Cookie、サイトデータが残ります。mail.example.com を残すと example.com の Cookie も残ります。サブドメインのログイン情報がそこに入っていることが多いためです。

設定を開く

インストール後に設定が自動的に開くので、消去をオンにする前に一覧を作れます。その後は、ツールバーの拡張機能アイコンをクリックするか、次の手順で開きます:

1. ツールバーの拡張機能アイコンを右クリックします。
2. [オプション] を選択します。

起動時の消去

インストール直後は消去がオフなので、指示するまで何も削除されません。設定には「消去はオフです」というお知らせと「消去をオンにする」ボタンが表示されます。オンにすると、まず警告が表示されます。起動のたびに、残すサイト以外のすべてのサイトの履歴と Cookie が削除され、それらのサイトから（残すサイトがない場合はすべてのサイトから）ログアウトされます。

オンにすると、消去はブラウザの起動のたびに実行されます。ブラウザは終了時に拡張機能を実行させないためです。起動時の消去は、前回のセッションが残したものを削除します。設定の「ブラウザの起動時に自動で消去する」でオフにしたり、オンに戻したりできます。

今すぐ消去と残りの消去

設定の「今すぐ消去」はすぐに消去します。残すサイトがない場合は、すべて削除されることを知らせる赤い警告が先に表示されます。設定には、最後の消去がいつだったか、履歴と Cookie をいくつ削除したかが表示されます。

消去でサイトの履歴と Cookie が削除されると、以降の消去ではそのサイトが見つからなくなるため、ローカルストレージ、データベース、キャッシュが残ります。「残りを消去」は消去を実行したあと、見つかったかどうかにかかわらず、残さないすべてのサイトのデータを削除します。ここではブラウザが除外できるのは完全一致のサイトだけなので、残すサイトのデータが残るのは、そのサイト自体と、消去で履歴・Cookie・開いているタブから見つかった残すサイトだけです。このことは赤い警告で先に伝えられます。

サイトへのアクセス

Cookie は拡張機能がアクセスできるサイトからしか削除できないため、すべてのサイトへのアクセスを求めます。サイトへのアクセスを「クリック時」などに制限すると、履歴は引き続き消去されますが Cookie はスキップされ、設定に「サイトへのアクセスを許可」ボタンが表示されます。

制限事項

• 起動時に復元されたタブは、消去の実行中に新しい Cookie を設定することがあります。その Cookie は次回の起動か「今すぐ消去」まで残ります。
• セッションストレージ、サイトの権限、File System API で保存されたファイルなど、その他のサイトデータは消去されません。
• ブラウザの同期に履歴が含まれている場合、削除した履歴はほかのデバイスからも削除されることがあります。
• シークレット ウィンドウは、拡張機能がシークレット モードで許可されている場合にのみ消去されます。いずれにしても Chrome は閉じるときにそのデータを破棄します。
• IPv6 アドレスは一覧に追加できません。

プライバシー

• 分析やトラッキングなし
• データ収集なし
• ネットワーク リクエストなし
• リモートコードなし
• 外部 JavaScript なし
• 履歴と Cookie は削除する対象を決めるためだけに、お使いのブラウザ内でのみ読み取られます
• 一覧と設定はお使いのブラウザ内にローカルに保存されます

パフォーマンス

拡張機能はブラウジング中は何もしません。動作するのは、消去がオンのときのブラウザ起動時に 1 回と、「今すぐ消去」または「残りを消去」をクリックしたときだけです。

長い履歴の最初の消去には数分かかることがあります。履歴は 1 件ずつ削除されるためです。その間もブラウジングを続けられます。以降の消去では前回のセッションの履歴だけが削除されます。
