브라우저가 시작될 때 보관하는 사이트를 제외한 모든 사이트의 방문 기록, 쿠키, 사이트 데이터를 삭제합니다.

Android용 Firefox는 확장 프로그램이 방문 기록을 삭제하도록 허용하지 않으므로, 그곳에서는 쿠키와 사이트 데이터만 삭제됩니다.

Clear Browsing Data Except Kept Sites는 유지하기로 선택하지 않은 모든 사이트의 방문 기록, 쿠키, 사이트 데이터를 삭제하는 가벼운 오픈 소스 확장 프로그램입니다.

설정에서 로그인 상태를 유지하고 싶고 기억해 두고 싶은 사이트를 추가한 다음 삭제를 켜세요. 브라우저가 시작될 때마다 확장 프로그램이 다른 모든 사이트의 방문 기록과 쿠키를 삭제합니다. '지금 삭제'로 언제든지 삭제할 수도 있습니다.

주요 기능

• 방문 기록과 쿠키가 절대 삭제되지 않는 사이트 목록, 텍스트 파일로 가져오기 및 내보내기 지원
• 켜 두면 브라우저 시작 시 다른 모든 사이트의 방문 기록과 쿠키 삭제
• 설정의 '지금 삭제'로 언제든지 삭제
• 유지하는 사이트의 하위 도메인 자동 유지
• 유지하는 사이트에서 로그인 상태를 유지하는 데 필요한 상위 도메인 쿠키 유지
• 분할된(서드파티) 쿠키와 컨테이너 쿠키 삭제. 유지하는 사이트의 분할된 쿠키는 유지하는 사이트 아래에 있는 것만 남습니다
• 유지하지 않는 사이트의 로컬 저장소, IndexedDB, 서비스 워커, 캐시 삭제
• 설정에 마지막 삭제 결과 표시
• 사이트 액세스가 꺼져 있어 쿠키를 삭제할 수 없을 때 경고
• 분석 또는 추적 없음
• 원격 코드 또는 네트워크 요청 없음

유지하는 사이트

설정을 열고 도메인을 추가하세요. 예:

example.com

여러 개를 한 번에 추가하려면 쉼표로 구분하세요.

'내보내기'는 목록을 한 줄에 도메인 하나씩 텍스트 파일로 저장합니다. '가져오기'는 목록을 텍스트 파일의 사이트로 바꾸며, 지금 유지하는 사이트가 사라지는 경우 먼저 경고합니다.

mail.example.com/inbox 같은 주소는 도메인만 남기고, 앞의 www.는 생략됩니다. localhost와 192.168.1.1 같은 IPv4 주소도 사용할 수 있습니다.

example.com을 유지하면 example.com과 모든 하위 도메인의 방문 기록과 쿠키가 유지됩니다. mail.example.com을 유지하면 example.com의 쿠키도 유지됩니다. 하위 도메인의 로그인 정보가 그곳에 들어 있는 경우가 많기 때문입니다.

설정 열기

설치 후 설정이 자동으로 열리므로 삭제를 켜기 전에 목록을 채울 수 있습니다. 나중에는 툴바의 확장 프로그램 아이콘을 클릭하세요. Android용 Firefox에서는 브라우저의 확장 기능 메뉴에서 Clear Browsing Data Except Kept Sites를 탭하세요.

부가 기능 관리자에서 열 수도 있습니다.

1. Firefox 메뉴를 열고 부가 기능 및 테마를 선택합니다.
2. Clear Browsing Data Except Kept Sites을 찾아 옆에 있는 점 세 개 메뉴를 클릭합니다.
3. 설정을 선택합니다.

시작 시 삭제

설치 후에는 삭제가 꺼져 있으므로 요청하기 전까지는 아무것도 삭제되지 않습니다. 설정에 '삭제가 꺼져 있음' 알림과 '삭제 켜기' 버튼이 표시됩니다. 켜면 먼저 경고가 표시됩니다. 시작할 때마다 유지하는 사이트를 제외한 모든 사이트의 방문 기록과 쿠키가 삭제되고 해당 사이트에서(유지하는 사이트가 없으면 모든 사이트에서) 로그아웃됩니다.

켜 두면 브라우저가 시작될 때마다 삭제가 실행됩니다. 브라우저가 종료 시에는 확장 프로그램을 실행하지 않기 때문입니다. 시작 시 삭제는 이전 세션이 남긴 것을 삭제합니다. 설정의 '브라우저가 시작될 때 자동으로 삭제'에서 끄거나 다시 켤 수 있습니다.

지금 삭제

설정의 '지금 삭제'는 즉시 삭제합니다. 유지하는 사이트가 없으면 모든 것이 삭제된다는 빨간 경고가 먼저 표시됩니다. 설정에는 마지막 삭제가 언제였는지, 방문 기록과 쿠키를 몇 개 삭제했는지가 표시됩니다.

사이트 액세스

쿠키는 확장 프로그램이 액세스할 수 있는 사이트에서만 삭제할 수 있으므로 모든 사이트에 대한 액세스를 요청합니다. 사이트 액세스를 끄면 방문 기록은 계속 삭제되지만 쿠키는 건너뛰며, 설정에 '사이트 액세스 허용' 버튼이 표시됩니다.

제한 사항

• 시작 시 복원된 탭은 삭제가 실행되는 동안 새 쿠키를 설정할 수 있습니다. 이 쿠키는 다음 시작 또는 '지금 삭제'까지 남습니다.
• Firefox는 선택한 사이트를 제외하고 사이트 데이터를 삭제할 수 없으므로, 확장 프로그램은 방문 기록, 쿠키, 열린 탭에서 찾은 유지하지 않는 각 사이트의 로컬 저장소, IndexedDB, 서비스 워커를 삭제합니다. 이 중 어디에도 나타나지 않는 사이트는 데이터가 유지됩니다. 유지하는 하위 도메인이 있는 사이트는 서비스 워커가 유지됩니다. Firefox가 하위 도메인의 서비스 워커까지 함께 삭제하기 때문입니다. 캐시는 Firefox가 사이트별로 삭제할 수 없으므로 모든 사이트에서 삭제되지만, 이로 인해 로그아웃되지는 않습니다.
• Firefox는 Cache Storage, 즉 서비스 워커가 저장하는 오프라인 파일을 사이트별로 삭제할 수 없으므로 이는 삭제되지 않습니다. 확장 프로그램이 닿지 않는 데이터를 삭제하려면 설정 > 개인 정보 및 보안 > 쿠키 및 사이트 데이터 > 데이터 관리를 사용하세요.
• 브라우저 동기화에 방문 기록이 포함되어 있으면 삭제한 방문 기록이 다른 기기에서도 삭제될 수 있습니다.
• 사생활 보호 창은 확장 프로그램의 실행이 허용된 경우에만 삭제됩니다.

개인정보 보호

• 분석 또는 추적 없음
• 데이터 수집 없음
• 네트워크 요청 없음
• 원격 코드 없음
• 외부 JavaScript 없음
• 방문 기록과 쿠키는 삭제할 항목을 결정하기 위해서만, 브라우저 안에서만 읽습니다
• 목록과 설정은 브라우저에 로컬로 저장됩니다

성능

확장 프로그램은 브라우징하는 동안 아무것도 하지 않습니다. 삭제가 켜져 있으면 브라우저 시작 시 한 번, 그리고 '지금 삭제'를 클릭할 때만 실행됩니다.

긴 방문 기록을 처음 삭제할 때는 몇 분이 걸릴 수 있습니다. 방문 기록 항목을 하나씩 삭제하기 때문입니다. 그동안 계속 브라우징할 수 있습니다. 이후의 삭제에서는 이전 세션의 항목만 삭제됩니다.
