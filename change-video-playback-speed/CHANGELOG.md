## [1.0.4] - 2026-10-17

### Changes

* Works on GooglebookOS, with the same Alt+S keyboard shortcut as on ChromeOS.
* Firefox needs version 153 or later, on the desktop and on Android.
* Chrome and Edge need version 114 or later.

### Bug Fixes

* The speed indicator shows over fullscreen video players.
* Screen readers announce the new speed.
