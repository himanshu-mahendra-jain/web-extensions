클릭 한 번이나 키보드 단축키로 동영상과 오디오의 재생 속도를 바꿉니다.

Change Video Playback Speed는 유용한 재생 속도 네 가지를 차례로 바꾸는 가벼운 오픈 소스 확장 프로그램입니다.

1배 → 1.2배 → 1.5배 → 2배 → 1배

확장 프로그램 아이콘을 클릭하거나 키보드 단축키를 사용하면 다음 속도로 바뀝니다. 선택한 속도는 지원되는 삽입 플레이어를 포함해 페이지의 동영상과 오디오에 적용됩니다.

현재 속도는 페이지에 잠시 표시되고 툴바 배지에도 표시됩니다.

주요 기능

• 클릭 한 번과 키보드 단축키로 조작
• 동영상과 오디오 지원
• 호환되는 삽입 플레이어 지원
• 툴바의 속도 배지와 전체 화면에서도 보이는 페이지 표시
• 팝업 메뉴, 플로팅 컨트롤러, 설정 없음

기본 키보드 단축키

• Windows, Linux, ChromeOS, GooglebookOS, Android: Ctrl+Shift+Period
• macOS: Command+Shift+Period

키보드 단축키 바꾸기

1. Firefox 메뉴를 열고 부가 기능 및 테마를 선택합니다.
2. 확장 기능 페이지에서 톱니바퀴 아이콘을 클릭합니다.
3. 확장 기능 단축키 관리를 선택합니다.
4. Change Video Playback Speed를 찾아 원하는 단축키를 입력합니다.

개인정보 보호

• 분석이나 추적 없음
• 데이터나 방문 기록을 수집하지 않음
• 네트워크 요청 없음
• 웹사이트에 대한 상시 액세스 없음

속도 변경은 모두 브라우저 안에서 로컬로 이루어집니다.
