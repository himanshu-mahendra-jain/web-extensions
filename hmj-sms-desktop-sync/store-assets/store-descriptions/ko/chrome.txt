Android 휴대전화로 수신되는 SMS 메시지와 OTP 인증 코드를 데스크톱 알림으로 확인하세요. 엔드투엔드 암호화 지원 및 원클릭 복사 기능 제공.

HMJ SMS Desktop Sync는 Android 휴대전화의 HMJ SMS 앱과 연동되는 가볍고 안전한 오픈 소스 확장 프로그램입니다. 휴대전화로 메시지가 수신되면 즉시 데스크톱 화면에 표시되어, 스마트폰을 직접 들지 않고도 로그인 인증 코드를 바로 복사할 수 있습니다.

메시지는 브라우저 자체 푸시 서비스를 통해 휴대전화에서 브라우저로 직접 전달되며, 오직 이 브라우저만을 위해 암호화됩니다. 중간 서버가 전혀 존재하지 않으며, 푸시 서비스조차 메시지 내용을 읽을 수 없습니다.

팁: Chrome 확장 프로그램 메뉴(퍼즐 조각 아이콘)에서 고정해 두면 툴바에서 언제나 편리하게 이용할 수 있습니다.

주요 기능

• 휴대전화로 들어오는 모든 SMS에 대한 실시간 데스크톱 알림
• 알림 창의 'OTP 복사' 및 '메시지 복사' 버튼 지원. 알림을 클릭하면 OTP(코드가 없을 경우 메시지 전체) 자동 복사
• 툴바 팝업을 통한 최근 메시지 목록 확인 및 원클릭 복사
• 어떤 휴대전화와 어떤 SIM 카드로 수신되었는지 표시 (예: SIM 2: Jio)
• 여러 대의 스마트폰 연동 지원. 개별 연결 해제 또는 새 페어링 코드로 일괄 해제 가능
• QR 코드 스캔 한 번으로 계정 가입이나 로그인 없이 즉시 페어링
• 표준 Web Push 규격(RFC 8291 및 RFC 8292) 기반의 강력한 엔드투엔드(E2EE) 종단간 암호화
• 키보드 및 스크린 리더 접근성 완벽 지원, 다크 모드 및 고대비 색상 테마 지원
• 중앙 서버 없음, 사용자 분석 없음, 추적 기능 없음

휴대전화 연동 방법

1. 툴바의 HMJ SMS Desktop Sync 아이콘을 클릭하여 페어링 QR 코드를 엽니다.
2. 스마트폰에서 HMJ SMS 앱을 실행하고 메뉴에서 'Desktop Sync'를 선택합니다.
3. 'QR 코드 스캔'을 탭한 뒤 컴퓨터 화면의 코드를 스캔합니다.

연결이 완료되면 데스크톱에 연결 확인용 테스트 알림이 표시됩니다. 다른 휴대전화를 추가하려면 팝업에서 '다른 기기 페어링'을 클릭하세요.

페어링 코드에는 브라우저와의 통신을 위한 암호화 키가 포함되어 있습니다. 반드시 본인의 휴대전화에서만 확인하거나 입력하시고, 클립보드 공유나 화면 공유 프로그램에 노출되지 않도록 주의하세요.

인증 코드 복사 방법

인증 코드가 포함된 메시지가 도착하면 알림에서 'OTP 복사'를 클릭하거나 알림 자체를 클릭하여 필요한 곳에 바로 붙여넣으세요. 전송 후 10분 이상 지연되어 수신된 OTP는 만료된 것으로 처리되어 메시지 본문만 복사할 수 있습니다.

연결된 기기 관리

팝업 상단의 휴대전화 이름을 클릭하면 연결된 기기 목록과 마지막 활동 시간을 확인하고 개별 연결을 해제할 수 있습니다. 연결이 해제된 기기의 메시지는 컴퓨터에서 무시됩니다.

팝업 메뉴(⋮)에서는 새 페어링 코드를 생성하여 모든 기기의 접근을 차단하고 저장된 메시지를 지우는 '모든 휴대전화 연결 해제' 및 '메시지 지우기' 기능을 지원합니다.

몇 달 동안 메시지 수신이 없어 브라우저가 푸시 연결 주소를 만료시키는 등의 경우, 팝업 창에 안내가 표시되며 각 스마트폰에서 다시 스캔할 수 있는 새 QR 코드가 나타납니다.

개인정보 보호

• 서버 없음: 메시지는 브라우저의 푸시 서비스를 통해 휴대전화에서 컴퓨터로 직접 전송되며, 이 브라우저에서만 해독할 수 있도록 암호화됩니다
• 사용자 데이터 분석이나 행동 추적을 일체 수행하지 않습니다
• 외부 스크립트나 원격 코드를 실행하지 않습니다
• 메시지 내용, 기기 이름, 페어링 키는 오직 사용자 브라우저 로컬에만 보관됩니다
• 24시간이 지난 메시지는 자동으로 삭제되며, 최대 100건까지만 보관됩니다
• 메뉴의 '메시지 지우기' 또는 '모든 휴대전화 연결 해제'를 통해 저장된 모든 데이터를 언제든 한 번에 삭제할 수 있습니다

요청 권한 안내

• 알림(Notifications): 수신된 메시지를 데스크톱 알림으로 표시하기 위해 사용합니다
• 클립보드(Clipboard): 알림이나 복사 버튼 클릭 시 OTP 코드 및 텍스트를 클립보드에 복사하기 위해 사용합니다
• 저장소(Storage): 연결된 기기 정보 및 최근 메시지 기록을 브라우저에 안전하게 보관하기 위해 사용합니다
• 오프스크린 문서(Offscreen): 백그라운드 서비스 워커가 클립보드에 데이터를 안전하게 기록할 수 있도록 지원합니다

이용 시 참고사항

• Android 스마트폰에 HMJ SMS 앱이 설치되어 있어야 합니다.
• 확장 프로그램에서 특정 기기의 연결을 해제하면 수신은 차단되지만 스마트폰 자체에서의 전송을 멈추려면 휴대전화의 HMJ SMS 앱에서도 연결을 해제해야 합니다. 또는 '모든 휴대전화 연결 해제'를 실행한 뒤 유지할 기기만 새 QR 코드로 다시 페어링하세요.
